M365

Non-technical · 10 candidates

Survey signal: Microsoft Copilot, Office work, research, documents, meetings, and data.

  1. N1

    Finding exact details in long documents takes too long.

    Repeated signal

    Respondents mentioned hard-to-find information and searching lengthy agreements.

    Simple scenario with Microsoft Copilot

    Situation: Before a supplier meeting, someone needs to find renewal dates and notice periods in a long agreement.

    AI assist: Use Word Copilot or an approved Copilot Chat file workflow to locate relevant sections, summarize them, and list unanswered questions.

    Human check: Open each cited or named section and verify the exact wording and dates in the agreement.

    Open the full example
  2. N2

    Tracking correspondence across documents is manual.

    Directly mentioned

    A respondent described building an Excel register from SharePoint documents.

    Simple scenario with Copilot Chat + Excel

    Situation: A coordinator receives a folder of approved letters and needs a register of date, sender, recipient, subject, and reference number.

    AI assist: Ask Copilot to extract fields from a small, approved sample into a table; continue in Excel and leave uncertain fields blank.

    Human check: Compare rows with source files, confirm the record count, and correct ambiguous names or dates.

    Open the full example
  3. N3

    It is unclear what Copilot can access across work sources.

    Directly mentioned

    Questions named SharePoint file access, agents, and getting information from Confluence.

    Simple scenario: find an approved source

    Situation: A team member needs the current procedure but does not know whether it lives in SharePoint or Confluence.

    AI assist: Test Copilot against a known SharePoint file the user can already access. For Confluence, use only an approved connector or approved export if one exists.

    Human check: Confirm the source and permissions. Copilot cannot grant access or bypass a missing connection.

  4. N4

    Repetitive administrative work keeps taking attention.

    Directly mentioned

    A respondent called out frequent, necessary tasks that feel routine and boring.

    Simple scenario with Copilot Chat + Word

    Situation: Every Friday, a team lead turns rough notes and approved status rows into the same weekly update.

    AI assist: Provide the approved inputs and last week's template; ask Copilot to draft this week's update and flag missing owners or dates.

    Human check: Verify each status against its source and make the final decision about what to publish.

  5. N5

    Spreadsheet analysis is a point where people want help.

    Repeated signal

    Data analysis appeared as a requested topic and among reported Copilot tasks.

    Simple scenario with Copilot in Excel

    Situation: A project coordinator needs to find overdue actions and summarize them by owner in a tracking sheet.

    AI assist: Ask Copilot to identify the relevant columns, suggest a formula or filter, and summarize the resulting rows.

    Human check: Inspect the formula, filters, and a few source rows; do not treat a generated summary as a verified calculation.

GH

Technical · 10 candidates

Survey signal: GitHub Copilot, coding, debugging, tests, documentation, and client constraints.

  1. T1

    Debugging can take too long before the real cause is clear.

    Repeated signal

    Debugging and root-cause analysis were among the most frequently selected AI tasks.

    Simple scenario with GitHub Copilot Chat

    Situation: A developer has a failing unit test and a stack trace but is unsure which code path to inspect first.

    AI assist: In the sandbox repo, share the failing test and relevant sanitized trace; ask Copilot for likely hypotheses and the smallest check that distinguishes them.

    Human check: Reproduce the failure, run the suggested test, and confirm the cause from code and runtime evidence.

    Open the full example
  2. T2

    Generated tests are not consistently good enough to trust.

    Directly mentioned

    A respondent wanted help writing tests but said the quality had not met their standards.

    Simple scenario with GitHub Copilot

    Situation: A function handles ordinary input, but its tests do not cover empty values, boundaries, or failure behavior.

    AI assist: Ask Copilot to list missing cases first, then draft tests that follow the repository's existing test style.

    Human check: Review what each assertion proves, run the tests, and confirm they fail when the behavior is deliberately broken.

    Open the full example
  3. T3

    Reviewing and fixing AI output can erase the time saved.

    Repeated signal

    Several respondents described productivity as neutral, with review or fixes taking comparable effort.

    Simple scenario: review a small Copilot-assisted diff

    Situation: A developer has a plausible change but spends as long checking it as writing it.

    AI assist: Give Copilot Chat the ticket and diff; ask for prioritized mismatches, missing tests, and assumptions with file-level evidence.

    Human check: Verify each finding independently and compare review time and defect coverage with the usual process.

    Open the full example
  4. T4

    Legacy refactors and broad code changes are hard to scope safely.

    Repeated signal

    Refactoring and modernization appeared as recurring tasks; one example involved replacing package calls across a codebase.

    Simple scenario with GitHub Copilot

    Situation: A package call must be replaced with a team wrapper, and the change appears in many files.

    AI assist: Ask Copilot to locate representative usages, propose a small migration plan, then update one bounded slice at a time.

    Human check: Search for remaining old calls, review the full diff, and run targeted plus regression tests before widening the change.

    Open the full example
  5. T5

    Routine code, scripts, SQL, and engineering docs compete for focus.

    Repeated signal

    Boilerplate, infrastructure, SQL, technical documentation, and reports appeared across responses.

    Simple scenario: investigate a slow SQL job

    Situation: A scheduled Oracle query sometimes times out, and the team wants a focused optimization hypothesis.

    AI assist: In Copilot Chat, provide a sanitized query, schema summary, and execution plan; ask for candidate bottlenecks and a test plan.

    Human check: Benchmark only in a non-production environment with representative data; verify the query plan and result equivalence.

    Open the full example
  6. T6

    Turning unclear requests or mockups into actionable tasks takes effort.

    Directly mentioned

    A respondent reported substantial manual effort creating detailed Jira tasks from UI mockups.

    Simple scenario: mockup to Jira-ready tasks

    Situation: A developer receives a screen mockup and a short feature request with several unanswered design questions.

    AI assist: Use GitHub Copilot with the mockup where image input is supported, or describe it; draft small UI/API tasks, acceptance criteria, and open questions. An approved CLI or MCP integration can prepare Jira drafts.

    Human check: A person resolves design decisions and approves every Jira write. Copilot itself does not grant Jira access.

    Open the full example
  7. T7

    Finding useful context or answers to unfamiliar problems is slow.

    Directly mentioned

    Respondents named searching for solutions, understanding code, and investigating difficult issues.

    Simple scenario with GitHub Copilot Chat

    Situation: A developer joins an unfamiliar repository and needs to find where a specific validation rule lives.

    AI assist: Ask Copilot to trace the behavior through the open workspace and identify likely files and tests to inspect.

    Human check: Open those files, follow the actual call path, and confirm the explanation matches the code and tests.

    Open the full example
  8. T8

    Explaining technical work in business language takes extra effort.

    Directly mentioned

    One respondent specifically wanted to translate technical notes into business-facing language.

    Simple scenario with GitHub Copilot Chat

    Situation: A developer must explain a release change and its impact to a non-technical project lead.

    AI assist: Provide verified change notes and ask Copilot to draft a plain-language summary with impact, limitations, and outstanding risks.

    Human check: Confirm the summary does not promise behavior or timelines that the code and release plan do not support.

    Open the full example
  9. T9

    Client rules can block access to the context AI would need.

    Directly mentioned

    Responses described customer restrictions on AI use, MCP servers, and access to client data.

    Simple scenario: work inside the approved boundary

    Situation: A developer wants Copilot help, but the client repository or data is not approved for that tool.

    AI assist: Do not send restricted context. Practice the workflow in a public or synthetic repository, or use only an explicitly approved client environment.

    Human check: Confirm policy and tool approval with the client. Copilot cannot remove a restriction or make unapproved data safe.

    Open the full example
  10. T10

    AI use often stays basic instead of becoming a repeatable workflow.

    Validate with users

    Many respondents relied on default settings; confirm whether shared instructions, skills, or CLI workflows would address a real pain.
